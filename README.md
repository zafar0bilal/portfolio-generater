# Freelancer Portfolio Generator

A static, GitHub Pages-friendly portfolio generator.

## Features
- 24 different visual portfolio templates
- Information form for profile, skills, services, experience and social links
- Add up to 6 projects
- Profile photo upload
- Live portfolio preview
- Template search and category filter
- LocalStorage autosave
- Full-screen preview
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a browser.

For the smoothest local experience, use VS Code + Live Server.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js`.
3. Open Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
