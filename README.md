# Freelancer Portfolio Generator — V5

This version uses **exactly the six latest portfolio reference images uploaded by the user** as visual inspiration.

## Six templates only
1. Crimson Editorial — bold red/black creative portfolio
2. Warm Luxury — cinematic warm/brown premium portfolio
3. Golden Showcase — black/gold editorial portfolio
4. Neon Arena — esports/gaming portfolio
5. Glass UI — futuristic interactive glass-style portfolio
6. Blue Grid — graphic designer/editorial grid portfolio

The designs are inspired by the references without copying them exactly. The six templates have different layout structures, typography, image placement and fixed animation behavior.

## Fixed animations
The user does not choose the animation. Each template has its own built-in motion:
- Reveal
- Slow scale/parallax feel
- Staggered entrance
- Glitch/pulse
- Floating
- Wipe/reveal

## Images
The six reference images are stored in:
`assets/presets/preset-01.png` through `preset-06.png`

Users can upload:
- Profile picture
- Project/work picture for every project

Project images support **Show full image** / **Fill frame** and focus position controls.

## Social profiles
Users enter usernames/handles instead of URLs for Instagram, LinkedIn, GitHub, Behance and Dribbble. The generated portfolio shows clickable icons that open the corresponding profiles.

Upload the entire folder contents, including the `assets/presets/` folder, to GitHub Pages.
