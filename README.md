# Freelancer Portfolio Generator — V2

A GitHub Pages-friendly no-code portfolio generator with 24 aesthetic templates.

## New in V2
- 24 templates with different visual styles
- Different font pairings across templates
- Different hover/entrance animation treatments
- Profile picture upload
- **Project/work picture upload for every project**
- Up to 6 projects
- Live preview updates instantly
- Search and filter templates
- Local browser autosave
- Full-screen preview
- Export the current portfolio as an HTML file
- Responsive generator UI

## How to add a work picture
Go to **02 — Your Work** → each project has **Upload work picture** → select JPG/PNG/WEBP → the image appears in the live portfolio preview.

## GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `styles.css`, and `app.js` to a GitHub repository.
3. Go to Settings → Pages.
4. Choose the `main` branch and `/ (root)`.
5. Save.

## Important
This version is client-side. Uploaded images are stored as browser data and embedded in the generated HTML preview. For a production SaaS version with user accounts and permanent portfolio URLs, add a backend/database and cloud image storage.
